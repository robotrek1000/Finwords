# Finwords

Finwords — самостоятельная образовательная web-игра о финансовых терминах.
Публичная версия включает пользовательские сценарии P1–P5 и работает полностью
локально: небольшой `fetch`-клиент обращается к `/demo-api/*`, а MSW обслуживает
эти запросы прямо в браузере.

## Публикация

GitHub Actions проверяет проект и публикует `main` на GitHub Pages:

<https://robotrek1000.github.io/Finwords/>

Production-сборка использует base path `/Finwords/`. Все игровые изображения,
шрифты и service worker загружаются относительно этого пути.

## Локальная работа

```bash
npm ci --ignore-scripts
npm run dev
```

Основные команды:

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run test:e2e:pages
```

## Состояние игры

Каждая загрузка страницы начинается с чистого Home: нулевых знаний, начального
баланса, первого доступного уровня и исходных настроек, наград и обликов.
Browser-версия не сохраняет mock-состояние. Test-only persistence используется
только unit-тестами миграции старого формата.

## Устройства

На экранах шириной до 430 px игра занимает всю доступную ширину и фактическую
высоту visual viewport, включая safe-area iPhone. На широких экранах игра
центрируется во фрейме до 430 × 932 px.
