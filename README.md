# Финворды

Полная браузерная игра: **7 глав и 50 уровней**, обучение, подсказки, награды,
оформление, музыка и звуковые эффекты.

Игра: https://robotrek1000.github.io/Finwords/

## Запуск

Требуется Node.js 24. Установите зависимости командой `npm ci`, затем `npm run dev`.
`npm run build` создаёт `dist`, `npm run preview` запускает готовую сборку.
Для сборки и preview по пути GitHub Pages задайте переменную окружения
`VITE_BASE_URL=/Finwords/`. В PowerShell: `$env:VITE_BASE_URL='/Finwords/'`.

## Как работает публикация

GitHub Actions проверяет код и публикует `dist` при отправке в `main`.
Workflow также можно запустить вручную через Actions → Deploy GitHub Pages.
Pages использует окружение `github-pages` и базовый путь `/Finwords/`.

Production полностью работает в браузере: MSW обслуживает игровые запросы
без отдельного сервера, учётной записи или корпоративной инфраструктуры.
Готовые данные кампании находятся в `src/content/mock-generated/campaign`.
Учебные предложения и отзывы являются локальной частью демонстрации.

После обновления страницы прогресс, награды и настройки сбрасываются.
Музыка и звук включены по умолчанию и начинают воспроизводиться после первого
касания или нажатия. Настройки позволяют отключать их независимо.
Для совместимости есть оригинальные OGG и MP3-копии тех же четырёх записей.
В скрытой вкладке музыка приостанавливается.

Разработка сохраняет диагностические сценарии и локальное состояние для тестов;
`?mockPersistence=off` отключает это сохранение. Production не включает тестовые
сценарии и всегда начинает новую игру.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

После сборки с `VITE_BASE_URL=/Finwords/` выполните `npm run test:e2e:pages`.
Production-тесты проходят кампанию от первого до пятидесятого уровня без
пропусков и проверяют настоящий звук, ресурсы, настройки и сброс состояния.

## Откат

Отмените коммит публикации командой `git revert <commit>` и отправьте обычным
`git push origin main`. Actions проверит и опубликует предыдущую версию.
Не используйте force push: история репозитория сохраняется.

Полная исходная копия Mac с документацией и прежней Git-историей хранится
отдельно. Этот репозиторий содержит рабочий фронтенд и его проверки.
